# 电影推荐技能

## 流程
1. 向用户收集偏好：类型（喜剧/科幻/悬疑/动画…）、年代范围、观影心情（放松/刺激/治愈）
2. 使用 calculator / 时间工具不需要；直接基于常识推荐即可（离线环境无实时榜单）
3. 每部推荐给出：片名、年份、一句话理由、适合场景

## 输出格式
```
🎬 推荐清单（基于你的偏好）
1. 《xxx》（2024）— 理由
2. ...
适合 xx 场景观看
```

## 注意
- 手机端离线运行，不要声称"最新热映"数据实时
- 用户只要一部时给一部，不要堆砌
