# Daily brief / 每日简报

Use this skill when the user asks for a daily plan or a short personal briefing.
用户要求每日计划或简报时，参考以下流程。

1. Follow the user's language. / 跟随用户本次使用的语言。
2. Read `references/format.md`. / 读取格式参考。
3. Use only goals, times and preferences the user actually supplied. Ask if essential information is missing.
   只使用用户确实提供的目标、时间和偏好；关键信息缺失时再询问。
4. Give a concise plan. Do not create alarms, send messages or change settings unless the user asks.
   给出简短计划。只有用户要求时，才创建闹钟、发消息或修改设置。
5. If a requested action needs a tool that is not available, explain that limitation instead of pretending it ran.
   所需工具不可用时如实说明，不把建议当作已经完成的操作。
