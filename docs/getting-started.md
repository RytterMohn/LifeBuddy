# 安装与使用

LifeBuddy 是运行在 Android 上的个人 Agent。当前为 alpha，最低 Android 8.0 / API 26；默认使用你配置的云端模型，无需模型权重或 root 权限。

## 安装

从 [GitHub Releases](https://github.com/RytterMohn/LifeBuddy/releases) 下载 APK。首个公开版本为 `0.2.0-alpha18`，使用 debug 测试签名，包名保留 `dev.ondevice.gemma.app`，以兼容此前安装的数据。

相同签名的 APK 可以覆盖安装。自行构建和 CI 产物通常使用不同的 debug 签名，Android 可能拒绝覆盖已有安装；不要为了安装而随意清除数据，因为卸载会删除会话、记忆和配置。各次公开下载请优先使用 Releases 提供的包。

## 配置模型

侧边栏 → 设置，填写：

- HTTPS API 基础地址，通常以 `/v1` 结尾，不包含 `/chat/completions`。
- 服务商实际提供的模型 ID。
- 自己的 API Key。

服务需要支持 Chat Completions、function tools 和流式聊天。Key 加密保存在本机；项目不提供公共账户或内置 Key。先在聊天模式问一个简单问题，确认配置可用。

## 两个模式

**聊天**：问答、写作、计算、读取技能资料、使用长期记忆。不能操作外部 App 或调用 MCP 业务工具。

**操作**：根据一句自然语言自主选择应用、界面步骤和已连接工具。先开启 LifeBuddy 无障碍服务。可以限制应用范围；默认允许从已安装应用中选择。

建议从“打开备忘录，新建并保存一条测试笔记”这样的短任务开始。后续消息会继续同一会话，只有“新对话”才建立另一个会话。

操作模式会按你的要求直接执行，包括发送消息，不逐步弹出批准窗口。暂停或停止后，已发出的消息、已经修改的设置和外部服务操作不会自动撤销。执行结果不明时先检查对应 App 或服务，不要把“结果待确认”理解为“没有执行”。

## 语言、记忆与学习

设置 → 界面语言：跟随系统、中文、English。新回答优先遵循你明确要求的语言；原对话和页面证据保留原文。

设置 → 长期记忆：查看、编辑、删除明确保存的偏好和事实。设置 → 学习与经验：管理从任务中产生的候选习惯和自动技能。学习只发生在主动交给 Agent 的任务中，不被动录制日常手机使用。

## 扩展

设置 → 扩展中心：导入 SKILL.md / ZIP 或连接 MCP。详见 [扩展说明](extensions.md)。自动生成的应用技能仍在“学习与经验”，不会被同名导入技能覆盖。

## 常见情况

- **无法操作手机**：检查无障碍服务、当前应用是否在允许范围，以及页面是否提供可访问控件。
- **回复为空或流式失败**：检查模型名称、基础地址和服务的流式/function tools 兼容性。
- **任务中断**：重新打开历史可查看当时结果；打开历史不会重放工具。需要继续时明确说明当前情况。
- **导入失败**：检查技能格式、ZIP 大小和路径；MCP 必须是 HTTPS Streamable HTTP 地址。桌面 command/npx 配置不能直接运行。
- **某个 App 失败**：系统版本、应用布局、登录状态和自绘控件都可能影响成功率，欢迎提交脱敏后的复现步骤。
