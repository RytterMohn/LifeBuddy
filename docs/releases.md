# Releases

## 0.2.0-alpha18

First public LifeBuddy alpha snapshot.

- Chinese / English interface and language-aware responses.
- Streaming chat, Markdown, persistent conversations and editable memory.
- Accessibility-based operation mode, system tools and reusable learned skills.
- SKILL.md / ZIP import and on-demand MCP HTTPS tools.
- Persisted external-call intent; interrupted calls are not automatically replayed.
- Chinese / English project documentation, MIT license, dependency notices and Android CI.

This is a debug-signed personal-testing build, not a production release. Android 8.0+ is required. Bring your own model endpoint and credentials. See [current limits](../README.en.md#current-limits) before testing phone operations.

APK files are distributed through [GitHub Releases](https://github.com/RytterMohn/LifeBuddy/releases), not committed to Git. Release downloads should include SHA-256 checksums. No API key, conversation history, model weight or signing key is part of the release.
