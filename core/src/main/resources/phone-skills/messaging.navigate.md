适用：当前获准的微信或 QQ 页面；这是导航参考，不保证所有版本布局相同。每步以最新快照为准。

1. 若已经在正确联系人聊天页，直接核对标题，不重复打开应用。否则从可见搜索入口查找联系人；搜索结果中的人名不等同于聊天页顶部标题。
2. 搜索时只填写搜索框；能提交搜索才使用 phone_submit_search。有的版本输入后即出现联系人结果，直接从当前结果选择，不反复等待键盘提交。
3. 依据用户指定名称区分联系人、群聊、公众号、聊天记录。存在同名或用户未说明对象时询问必要信息，不选择第一个相似名字。
4. 进入聊天页后核对顶部对象与可编辑的消息输入框。仅要求打开或查看时不要准备或发送消息；只要求草稿时保持 draftOnly=true。
5. 发信统一用 phone_prepare_message，channel=app，packageName 为实际应用；随后输入正文，用 phone_send_message 核对对象、正文与发送按钮后直接发送一次，无需二次征求同意。不能用 phone_tap 或提交搜索来代替发送。
6. 完成依据：草稿须读回对象与完整正文；已发送须看到相比本轮发送前新增的正文、输入框已清空且没有失败提示。旧气泡不能证明本轮发送成功，也不能声称对方已收到。

恢复：读不到标题或输入框时，先重新观察或回到可核对的会话；不要盲点无标签按钮。登录、权限或不可读页面按实际情况说明。不要将消息正文或联系人身份保存成通用应用导航经验。
