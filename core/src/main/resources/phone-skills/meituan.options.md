适用：用户要求选择外卖商品规格或准备购物车，已经在指定商家/商品页面。

1. 先核对商家及商品标题，再检查可选规格。用户本次明确的口味、数量、预算优先于历史偏好。
2. 规格选择后读回选中状态、数量和实际显示金额。缺货、必选项或价格变化时重新规划；不要根据旧页面连点。
3. 仅在用户要求加入购物车时使用可见的加购入口，并确认购物车里新增或更新的目标商品、规格和数量。相同名称的旧条目不能单独证明本次加购完成。
4. 重试之前先查看购物车是否已经改变，避免重复加购。任务结果保存当前选项与数量，供用户在同一对话里继续说明。

完成依据：规格页已选项或购物车中对应商品的可核对状态，应与用户本次目标一致。当前执行器不支持付款和提交订单；不要用无标签按钮、长按或其他动作绕过能力边界，也不要将准备购物车说成已经下单。
