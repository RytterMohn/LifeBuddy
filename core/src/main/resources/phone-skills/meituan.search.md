适用：当前获准的美团或美团外卖。只参考可见布局，不重放旧坐标。

1. 按目标选择业务：外卖、到店、酒店等不是同一个结果范围。用户要外卖时从可见“外卖”入口进入，再搜索商家或商品；已在正确业务内不重复启动应用。
2. 区分搜索框、推荐词、广告和附近商家。进入输入页后替换搜索词，提交明确的搜索动作；出现建议词不代表最终搜索结果已加载。
3. 核对搜索词、结果业务范围及商家/商品名称。读取价格时区分标价、券后价、起送价、配送费和规格差价，页面未显示的数值不推断。
4. 无结果时依据可见提示换用户允许的关键词或报告。动态加载时重新观察；弹层只能点击含义明确且符合当前目标的关闭或返回入口。
5. 用户只要求查找、比较、查看时到此结束，不把搜索扩展为加购或提交订单。商品规格任务可加载 meituan.options。

完成依据：提交后的商家或商品列表、目标详情，或明确无结果提示；不能仅引用搜索框文字就宣称找到商家。地址、登录和不可读取的页面按实际状态处理，不修改用户系统权限。
